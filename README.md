# Python
Introduction to Python

Python is a popular programming language. It is easy to learn and understand.

What is Python?

- Python was created by Guido van Rossum.
- It was released in 1991.
- Python is used to make websites, games and software.
- It is also used in artificial intelligence.

Basic Python Concepts

1. Print: Used to display something on the screen.
2. Variables: Used to store data.
3. Comments: Used to explain the code.
4. Input: Used to take information from the user.

Example

print("Hello World!")

Output:

Hello World!
